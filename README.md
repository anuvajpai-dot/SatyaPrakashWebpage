## सबसे ज़रूरी बात

**वीडियो की सूची हाथ से नहीं जोड़नी है।** वेबसाइट खुलते ही स्वयं आपके YouTube चैनल से
व्याख्यान उठा लेती है — असली शीर्षक, असली thumbnail और असली विवरण के साथ।
शीर्षक पढ़कर वह हर वीडियो को अपने आप सही अध्याय में रख देती है।

आप जो भी नया वीडियो अपलोड करेंगे, वह **अपने आप** वेबसाइट पर आ जाएगा।

## 1. होस्टिंग (2 मिनट, निःशुल्क)

**Netlify Drop**

1. ब्राउज़र में खोलिए: `https://app.netlify.com/drop`
2. `tripathi-website` फ़ोल्डर उठाकर उस पेज पर छोड़ दीजिए
3. तुरंत लिंक मिल जाएगा, जैसे `https://xyz-123.netlify.app`
4. निःशुल्क खाता बनाकर नाम बदला जा सकता है, जैसे `tripathi-lis.netlify.app`

**दूसरा विकल्प — GitHub Pages:** नया public repository बनाइए → `index.html` अपलोड
कीजिए → Settings → Pages → Branch `main`, Folder `/root` → Save।

> **ध्यान दीजिए:** वीडियो तभी आएँगे जब पेज किसी वेब पते (http/https) से खुले।
> सीधे कंप्यूटर से `file://` खोलने पर ब्राउज़र की सुरक्षा नीति उन्हें रोक देती है।
> इसलिए पहले होस्ट कीजिए, फिर देखिए।

## 2. API कुंजी — वैकल्पिक, पर संस्तुत

कुंजी के बिना साइट चलती है, पर **नवीनतम 15 व्याख्यान** ही आते हैं (एक निःशुल्क
सार्वजनिक सेवा के माध्यम से, जो कभी-कभी धीमी हो सकती है)।

कुंजी डालने पर **सभी व्याख्यान** आते हैं, तेज़ी से और स्थायी रूप से। कुंजी निःशुल्क है।

**कैसे बनाएँ (लगभग 3 मिनट)**

1. `https://console.cloud.google.com/` खोलिए और Google खाते से लॉगिन कीजिए
2. ऊपर से नया project बनाइए (कोई भी नाम)
3. बाईं ओर **APIs & Services → Library** → खोजिए **YouTube Data API v3** → **Enable**
4. **APIs & Services → Credentials → Create Credentials → API key**
5. कुंजी कॉपी कर लीजिए
6. सुरक्षा के लिए कुंजी पर **Edit** → *Application restrictions* में **Websites**
   चुनकर अपनी वेबसाइट का पता जोड़ दीजिए (जैसे `https://tripathi-lis.netlify.app/*`)

**कहाँ डालें** — `index.html` में यह पंक्ति खोजिए:

```js
const YT_API_KEY = "";
```

और कुंजी उद्धरण चिह्नों के भीतर लिख दीजिए:

```js
const YT_API_KEY = "AIzaSy........................";
```

फ़ाइल सहेजकर दोबारा अपलोड कर दीजिए। बस।

## 3. अध्यायों का वर्गीकरण

वेबसाइट वीडियो के शीर्षक में आए शब्दों से अध्याय पहचानती है — जैसे "वर्गीकरण",
"DDC", "सूचीकरण", "MARC", "शोध", "Koha", "NET"। जो वीडियो किसी अध्याय से मेल न
खाए, वह **"अन्य व्याख्यान"** में चला जाता है।

कोई वीडियो ग़लत अध्याय में दिखे तो `index.html` में `const KEYS = [` खोजिए और
उस अध्याय की सूची में एक शब्द जोड़ दीजिए।

सबसे आसान उपाय — YouTube पर वीडियो के शीर्षक में विषय का नाम रखिए, जैसे
*"पुस्तकालय वर्गीकरण — DDC की मूल संरचना"*। तब वर्गीकरण अपने आप सही होगा।
